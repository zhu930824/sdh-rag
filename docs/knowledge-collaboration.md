# 知识库协作权限

本阶段把知识库从“个人资料夹”升级为可复用的业务知识资产。权限由服务端统一判定，前端按钮隐藏只用于改善体验，不承担安全职责。

| 能力 | 所有者 | 编辑者 | 阅读者 | 公开访问者 |
|---|---:|---:|---:|---:|
| 查看、检索、预览关联文档 | 是 | 是 | 是 | 是 |
| 关联/移除文档、配置检索、标签、构建图谱 | 是 | 是 | 否 | 否 |
| 修改知识库基本信息、管理成员、删除知识库 | 是 | 否 | 否 | 否 |

## 约束

- 成员通过已有登录用户名授权，支持 `reader`、`editor` 两种权限；所有者权限不可转移。
- 文档仍有独立所有者。编辑者可以维护知识库，但只有文档所有者能把文档首次关联到其他知识库或删除源文件。
- 文档预览权限继承自其关联知识库；撤销私有知识库成员后，访问会立即失效。
- 公开知识库对所有已登录用户可读。移除显式成员并不会收回公开读取权限，应先改为私有。
- 工作流只允许所有者执行；每次执行检索节点都会重新校验知识库读权限，异步执行使用鉴权入口捕获的用户身份。
- 图谱浏览、构建、状态和路径查询必须带知识库范围并经过同一访问控制。

## 发布

部署后由 Flyway 执行 `V15__knowledge_members.sql`。该迁移只新增成员表，不改写现有知识库；现有所有者和公开访问行为保持不变。

## 下一步边界

当前模型是用户级协作 ACL，不等同于企业级多租户隔离。进入组织/空间阶段时，应补 `tenant_id`、部门/用户组授权、审计日志、数据源凭据隔离，并让评估任务与知识库沿用相同资源策略。

## 质量闭环

知识库详情的“质量闭环”页汇总最近 20 次已完成评估，将失败样本分为三类：未召回来源文档、召回文档但未命中正确分块、负样本错误召回。编辑者可将问题标记为已处理、忽略或重新打开，并记录处理说明。

评估任务创建需要知识库编辑权限，报告读取继承知识库读权限，删除任务只允许任务创建者或知识库所有者。评估任务由有界线程池执行，执行开始时会再次验证创建者的知识库权限。

部署时还需执行 `V16__evaluation_quality_issues.sql`，为历史和新评估问题增加处理状态与审计字段。
